# JavaScript Quiz App 💻

A simple and interactive quiz website built using HTML, CSS, JavaScript, and Bootstrap. Test your knowledge with multiple-choice questions while keeping track of your time.

## ✨ Features

- Interactive multiple-choice questions
- Question counter to track progress
- Countdown timer
- Stylish quiz card design
- Coding-themed background image
- Responsive layout
- Interactive buttons and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap

## 📂 Project Structure

```text
JavaScript-Quiz/
├── index.html
├── style.css
├── script.js
└── coding-bg.png
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all files and the background image are in the correct locations.
4. Open `index.html` in your browser, or run it using Live Server.

## 🎮 How to Play

1. Read the question displayed on the screen.
2. Select your answer from the available options.
3. Keep track of the remaining time.
4. Click **Next Question** to continue.

## 🎨 Customization

- Edit `style.css` to change the colors, background, and card design.
- Edit `script.js` to customize the quiz questions and functionality.
- Edit `index.html` to modify the page structure.
